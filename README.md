# Zingen - CSS Study Project

A responsive landing page for a fictional karaoke app, built as a study project to practice and demonstrate modern CSS concepts and techniques.

## Description

This project is a landing page for "Zingen," an AI-powered karaoke application, using HTML and CSS to create a modern, responsive design.

## CSS Concepts Studied

This project demonstrates the following CSS concepts and best practices:

- **CSS Custom Properties (Variables)**: Used extensively for theming, including colors, typography, spacing, and responsive values.
- **CSS Reset**: Applied universal box-sizing, margin/padding resets, and font smoothing for consistent rendering.
- **Responsive Design**: Implemented with media queries to adapt layouts, typography, and spacing for mobile and desktop views.
- **Modern Layout Techniques**: Utilized CSS Grid and Flexbox for flexible, responsive layouts.
- **Utility Classes**: Created reusable classes for common styles like padding, gaps, and display properties.
- **Nested Selectors**: Used the `&` nesting syntax for cleaner, more maintainable CSS.
- **Gradients and Background Effects**: Applied linear gradients for buttons and background images for sections.
- **Hover Effects**: Implemented interactive states using custom properties for dynamic color changes.
- **Typography System**: Built a scalable font system with variables for consistent text styling across breakpoints.
- **Background Clipping**: Used for advanced visual effects on buttons and icons.
- **Scroll Behavior**: Added smooth scrolling for better user experience.

## Project Structure

- `index.html`: Main HTML file with semantic structure.
- `styles/`: Organized CSS files for modularity:
  - `global.css`: Global styles, variables, and resets.
  - `utils.css`: Utility classes for layout and spacing.
  - `buttons.css`: Button component styles.
  - `socials.css`: Social media icon styles.
  - `header.css`: Header navigation styles.
  - `sections.css`: Section-specific styles.
  - `footer.css`: Footer styles.
  - `index.css`: Imports all other CSS files.
- `assets/`: Images and icons used in the design.

## Technologies Used

- HTML5
- CSS3 (Modern features like Grid, Flexbox, Custom Properties)

## How to View

Open `index.html` in your web browser to view the landing page. No build process or server required.

## Learning Outcomes

This project helped practice:
- Organizing CSS in a modular, maintainable way.
- Creating responsive designs that work on multiple screen sizes.
- Using CSS variables for easy theming and maintenance.
- Implementing modern layout techniques without relying on frameworks.
- Writing clean, semantic HTML that works with CSS layouts.
